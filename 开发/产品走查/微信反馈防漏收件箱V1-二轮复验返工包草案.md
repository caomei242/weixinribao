## P0 返工：固定应用壳

### 当前问题

当前只是“左边有导航”，但不是固定工作台：

- 顶部主线说明、状态卡、流程卡、群档案永远压在所有页面上方。
- 点击 `配置中心 / 草稿日报 / 转述摘要` 后，内容出现在页面下方。
- 用户仍需要下拉找模块。
- `配置中心` 实测在页面约 682px 后才开始，不是右侧工作区直接内容。
- 刷新停在配置中心时曾出现 `载入中...` 和日期时间空值 / 0 的中间态。

### 返工要求

改成草莓客户管理系统式应用壳：

```text
┌──────────────────────────────────────────────┐
│ 顶部：产品名 + 今日状态 + 少量全局动作        │
├──────────────┬───────────────────────────────┤
│ 左侧固定菜单 │ 右侧唯一工作区                 │
│ 今日防漏     │ 当前菜单对应页面                │
│ 试读消息     │                               │
│ 候选收件箱   │ 不下拉找模块                   │
│ 群客户打标   │ 不弹窗                         │
│ 草稿日报     │ 不纵向堆多个模块                │
│ 转述摘要     │                               │
│ 配置中心     │                               │
└──────────────┴───────────────────────────────┘
```

要求：

- `今日防漏 / 试读消息 / 候选收件箱 / 群客户打标 / 草稿日报 / 转述摘要 / 配置中心` 都必须渲染在右侧同一个主内容容器。
- `今日防漏` 承载主线说明、状态卡、流程步骤和收口清单；这些内容不能永远压在所有页面上方。
- 点击一级导航时，右侧直接整体切换，不触发页面下滚。
- 允许右侧模块内部局部滚动，例如消息列表滚动、候选列表滚动。
- 刷新后恢复当前页，并完成当前页加载。

### 验收标准

- 打开首页默认显示 `今日防漏`。
- 点击每个左侧菜单，右侧立刻显示对应模块，不需要浏览器下拉。
- 首页以外页面不再显示大块主线说明、流程卡和群档案压顶。
- 在 `配置中心` 刷新后仍是配置中心，且不长期卡 `载入中...`。
- 常见桌面窗口下，当前页标题、核心列表 / 表单、主要动作直接可见。

## P1 返工：候选池统一

### 当前问题

- 候选收件箱仍有 `当前工作台` 和 `最近真实试读` 两个来源。
- 切回 `当前工作台` 后候选数为 0。
- 切到 `最近真实试读` 后才看到 3 条候选。
- 用户被迫理解内部池子。

### 返工要求

- 产品上只暴露一个 `候选收件箱`。
- 默认展示当前最该处理的候选。
- 如果今日处理区为空但最近试读有 3 条候选，默认直接显示这 3 条。
- 内部来源只作为候选条目标签：`来自最近试读 / 已加入今日处理 / 已确认 / 已进草稿`。
- `加入待确认` 可以保留为状态动作，但不能成为看到候选的前置门槛。

### 验收标准

- 用户点击 `候选收件箱`，能直接看到 3 条待确认候选。
- 用户不需要先点 `最近真实试读`。
- 空状态只在确实没有任何候选时出现，并告诉用户下一步。

## P1 返工：文案改成人话

### 当前问题

主流程仍可见开发 / 审查词：

- `real_read_disabled`
- `tech / ops`
- `resolved`
- `本地 Markdown`
- `正式区`
- `导出`
- `未标对象`
- `审阅版`
- `待办池`

### 返工要求

- 技术状态默认进 `诊断详情`。
- 一级页面和主要卡片改成用户语言。
- 文案映射建议：
  - `real_read_disabled` -> `真实读取未开启`
  - `tech` -> `技术处理`
  - `ops` -> `运营处理`
  - `resolved` -> `已识别`
  - `pending` -> `待确认`
  - `none` -> `无风险`
  - `本地 Markdown` -> `本机草稿`
  - `正式区` -> `正式日报 / 正式待办`
  - `导出` -> `生成 / 复制摘要`
  - `未标对象` -> `待确认客户`

### 验收标准

- 主流程页面不出现 `workspace / real_trial / pending / none / tech / ops / resolved / real_read_disabled / formal_write`。
- 草稿日报默认写给用户审阅，不是后台字段堆叠。
- 转述摘要默认是可复制的人话结果，不是 Markdown 导出配置中心。

## P1 返工：客户打标只读匹配

### 当前问题

- V1 字段覆盖了客户名称、群负责人、业务模块、客户阶段、群类型、常用联系人、回复注意事项。
- 当前只有部分字段有值，大量显示未配置。
- 草稿日报 / 转述摘要仍可能显示 `未标对象`。
- 未看到从草莓客户管理系统自动只读匹配、推荐套用或人工确认的流程。

### 返工要求

- 只读接入草莓客户管理系统客户资料，不反向修改客户系统。
- 按群名、客户名、常用联系人、别名做匹配推荐。
- `群 / 客户打标` 页展示：
  - 匹配到的客户
  - 置信度 / 匹配依据
  - 可套用字段
  - 仍缺字段
  - 确认套用到本地配置
- 套用后同步影响候选收件箱、草稿日报和转述摘要。

### 验收标准

- 用户不需要从零手填客户名称、阶段、群类型、联系人和回复注意事项。
- 转述摘要里不再默认出现 `未标对象`。
- 匹配失败时，页面明确写 `未匹配到客户，请手动选择或新增本地映射`。
