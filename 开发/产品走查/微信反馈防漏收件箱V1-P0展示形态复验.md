# 微信反馈防漏收件箱 V1 P0 展示形态复验

时间：2026-05-18 17:02 CST

## 结论

P0 返工未完全通过。当前功能点有进步，但展示形态仍不是用户期望的固定工作台。

用户期望参考：草莓客户管理系统式布局。

```text
┌──────────────────────────────────────────────┐
│ 顶部：产品名 + 当前状态 + 少量全局动作        │
├──────────────┬───────────────────────────────┤
│ 左侧固定菜单 │ 右侧固定工作区                 │
│ 今日防漏     │ 当前菜单对应的完整页面          │
│ 试读消息     │                               │
│ 候选收件箱   │ 不靠下拉找模块                 │
│ 群客户打标   │ 不弹窗                         │
│ 草稿日报     │ 不把多个模块纵向堆叠            │
│ 转述摘要     │                               │
│ 配置中心     │                               │
└──────────────┴───────────────────────────────┘
```

## 当前实际表现

- 左侧导航已出现，但右侧不是固定工作区。
- 顶部主线说明、状态卡、流程卡、群档案永远占在所有页面上方。
- 点击 `配置中心 / 草稿日报 / 转述摘要` 后，模块内容出现在页面下方，用户仍要靠滚动找。
- `配置中心` 在本轮实测中位于页面约 682px 后才开始，说明它不是右侧工作区的直接内容。
- 刷新停在配置中心页后，页面保留在配置中心，但曾出现 `载入中...` 和日期时间空值 / 0 的中间态，刷新恢复仍需复核。

## 为什么这是 P0

用户实战要做的是每天处理消息防漏，不是操作开发后台。当前形态会让用户继续出现：

- 点了左侧菜单，不确定右边有没有变。
- 不知道是不是要往下滚。
- 看见一大块总览和空白，以为模块没加载。
- 配置、候选、草稿、转述像散落在一个长页面里，不像一个产品。

这直接命中用户原话：想要“左边点，右边变”，不是现在这样还要下拉。

## 返工要求

### P0-1 固定应用壳

- 页面只保留一个应用壳：
  - 顶部：产品名、简短状态、全局动作。
  - 左侧：固定一级导航。
  - 右侧：唯一主内容容器。
- 所有一级页面都渲染在右侧主内容容器里。
- 右侧内容切换时，不出现浏览器级纵向跳转。

### P0-2 今日防漏作为首页，不是全局压顶

- 当前主线说明、状态卡、流程步骤、今日收口清单都放进 `今日防漏` 页。
- 用户点击 `试读消息 / 候选收件箱 / 草稿日报 / 转述摘要 / 配置中心` 后，右侧只显示对应页面。
- 不允许主线说明和流程卡继续压在所有模块上方。

### P0-3 刷新恢复当前页

- 用户停在任意一级页面刷新后，仍停在该页面。
- 当前页面必须加载完成，不能长期显示 `载入中...`。
- 日期、筛选、数据源、当前候选选择等关键状态应恢复。

### P0-4 一屏内可工作

- 在常见桌面窗口下，点击一级菜单后，右侧主内容的标题、核心列表 / 表单、主要动作必须直接可见。
- 允许模块内部局部滚动，例如消息列表滚动、候选列表滚动。
- 不允许靠整个页面下拉来找模块入口。

## 建议给开发的结构改法

- `index.html` 建一个固定结构：`app-shell -> side-nav + main-panel`。
- `main-panel` 内部放 `今日防漏 / 试读消息 / 候选收件箱 / 群客户打标 / 草稿日报 / 转述摘要 / 配置中心` 页面。
- `.workspace-page.active-page` 只在 `main-panel` 内切换，不再作为独立 section 排在 `inbox-v1-workspace` 后面。
- CSS 让 `app-shell` 使用固定高度或 `calc(100vh - 顶部高度)`，左侧菜单固定，右侧内容区内部滚动。
- `setWorkspacePage()` 只负责切换 `main-panel` 内页面，不触发滚动，不打开旧弹窗逻辑。

## 验收标准

- 打开首页，默认显示 `今日防漏`。
- 点击 `试读消息`，右侧立刻显示消息页，不需要下拉。
- 点击 `候选收件箱`，右侧立刻显示候选页，不需要下拉。
- 点击 `草稿日报`，右侧立刻显示草稿页，不需要下拉。
- 点击 `转述摘要`，右侧立刻显示转述页，不需要下拉。
- 点击 `配置中心`，右侧立刻显示配置页，不需要下拉。
- 在 `配置中心` 刷新后仍是配置页，且不长期卡 `载入中...`。
- 首页以外页面不再显示大块主线说明、流程卡和群档案压顶。
- 主页面不出现 `workspace / real_trial / pending / none / real_read_disabled` 等用户不该看的开发词。

## 本轮不做

- 不要求本轮接入草莓客户管理系统自动打标。
- 不要求开启真实自动读取。
- 不要求写入正式日报 / 正式待办池。
- 不要求外发或复制真实原文。
